1．机位：让操作与结果同时可见

机位画面与用途拍摄要点
A：主机位斜前方中景，包含操作者双手、键盘、FPGA、HDMI屏和发声设备。锁定构图，保留若干不切镜头的“按键→屏幕→出声”片段。开场和三模式演示以它为主。
B：手部俯拍键盘、四Pad、四旋钮、两片FSR及两路光电。标记光电A/B，手不遮住关键标签。琴键与压力动作要能辨认；不可用后期快放充当响应证据。
C：屏幕特写 / HDMI采集演奏页、曲库页、FFT/李萨如、多维诊断及32路验证视图。避免反光、屏幕闪烁；若插入仿真图，醒目标注“RTL仿真预览”。与手部同期画面拼接时保持同步。
D：手机特写 / 录屏实际状态回读、JSON导入、完整提交、映射、WAV完成和下载。录屏辅以一段实拍连接关系；按键后等结果出现再切镜头。下拉选项和入队提示不是生效证据。
E：硬件近景FPGA、ESP32、MIDI接收、ADS、双光电与PCM5102A链路。短镜头配箭头即可。I²S为BCK=B12、LRCK=C12、DIN=B13；接线说明不等于电气指标测量。

只有一台拍摄设备时，先拍完整主机位演奏，再补特写；补拍的参数和曲目保持一致。手机既控制又拍摄不方便时，用电脑录屏或另一个现有设备；不必为本片新增设备。

声音来源分清：现场音用来证明扬声器/耳机模拟链路可听；FPGA WAV可用于干净的同期对照，标注“最终数字PCM录音”。WAV不包含PCM5102A、连线、音箱的模拟噪声，不能拿它证明模拟输出无噪声。禁用无关背景音乐，FX对比各段保持相同录音增益。

先短录检查收音不削顶；32路前降低音量。画面与音频可用一次明确的击键作同步标记。若用已录WAV替换现场音，保留同步关系并标注；不要把替换音轨拿来量输入延迟。

3．三模式与新原创和弦：关键镜头怎么拍

曲谱三模式为固定BPM检验 / 自动演奏 / 逐音练习；输入三模式为KEY / STRUM / HYBRID。前者决定曲谱走法，后者决定实际输入如何发声。三模式教学默认KEY，避免STRUM下按键只选和弦而误判无声。

曲谱模式最能说明行为的操作避免的误导
自动演奏先拍实际模式回读，开始后留出两拍预备；双手离开键盘，声音与谱面同步。切到FFT或其他页会暂停曲谱；不要剪成换页后仍自动播放的假连续过程。
逐音练习到目标时停住，按一次错误键仍停；松开后新按正确键，走完时值进入下一目标。连续同音要再按。不能拿提前按住或踏板延音充当新按键；实际状态读回比下拉框更可靠。
固定BPM检验留一拍不弹，谱面仍走；随后自己跟弹。它不等待、也不替用户自动演奏；没有自动评分和准确率结算的宣称。
V047和弦仅作待验证拍摄位：原创曲已保存为霓虹阶梯_黑白键双音四音_V047.json（59组、144音、32拍、116 BPM）。确定格式为tang20k.score/2，每个events组用pitches表示1..4个升序唯一音（MIDI41..72，F2–C5），同组共享start/duration/velocity，最多63组、不同组不能重叠。配套新FPGA与ESP47支持后，固定BPM、自动演奏及逐音和弦镜头才可标为实机功能；旧score/1单音继续兼容。
  1. 新曲选择：从“霓虹阶梯”中选10–15秒清晰片段；已落盘文件包含单音、双音、三音、四音组，音域41–72。片段的实际声音与显示效果仍须配套版本验收，文件存在不代表已烧录通过。
  2. 正向证据：自动演奏拍同组一起起音、一起结束；逐音在目标到达后新按各目标键并全部保持，满足后才推进。固定BPM保留漏弹仍继续的对照。
  3. 反例证据：将目标音逐个点下又松开，目标不应因此推进；只按部分目标保持也不能当作完成。再全部新按并同时保持，证明不是把先前零散按键简单累加。
  4. 恢复与备选：拍摄前恢复默认Note映射。V047未最终验证时保留V046实机三模式片段，并用上传验证_兼容V046单音.json（16个单音、8拍、100 BPM）；也可使用教程内三音示例。和弦内容只标待验证功能。

新曲上传到独立的自定义槽，三首预置曲保留；并非无限曲库或多轨伴奏。本文没有版权曲谱，也不直接提供《Bad Apple!!》转谱；用户提供有权使用的文件后可另行转换。主片优先使用新原创素材及自编功能检查片段。

4．手机三个闭环，必须拍到“结果”

JSON：导入 → 上传 → 实际运行

提前把文件放在手机，离线连接Tang20K-Music。拍清格式、导入有效但尚未上传、完整上传完成、自定义选中并开始、FPGA实际状态/屏幕响应。不要依赖在线URL，热点不提供互联网且URL还受CORS限制。文件保存与FPGA生效是两件事，重启FPGA后需重新上传/激活。

映射：完整交换 → 确认 → 原始显示对比 → 恢复

可直接导入映射演示_交换C4与D4.json。该文件已设panic_before_commit:true；导入会勾选提交前Panic，正式提交前核对停音选项。

先备份；交换60/62必须两项同时修改。松键、松踏板、停止演奏后提交，需要停音时显式勾选Panic；Panic会清持续音并停导奏。拍最终作业完成，再点“读取已保存 / 当前映射”显示本次确认。60发62、62发60，但高亮仍是原始键位；逐音比较仍看原始音。最后“提交 FPGA 默认映射”并实弹恢复，不能只点“编辑框恢复默认”。完整操作见详细教程。

若扩展拍摄Pad/CC映射，务必说明Pad是通道10来源、CC槽顺序是Delay/Chorus/Reverb/Volume，禁止1/7/64/120/121/123且四项互不重复。FX旋钮软接管后继续改变才选效果。主片时间有限时把这部分放补充镜头。

WAV：开始 → 实奏 → 排空校验 → 下载回放

演示前先下载要保留的上一段；开始新录音会替换它。最大30秒，依页面空间上限设置8–12秒即可。按停止后还要等EOF、序号、样本/长度、drops及CRC校验完成；“停止请求已发送”不是完成。录音期间暂停手机配置和导奏刷新，先选曲并启动再录；这不等于FPGA本身停止演奏。

拍到完整结果后才说“本段数字PCM录音校验通过”。重启后HTTP可读取保存WAV，但结构检查不等于当前再次通过FPGA CRC；不要把灰色/过期状态剪成当前实时读回。不要为拍片初始化LittleFS，它会清空曲谱、映射和录音。

5．哪些结论需要哪些证据

展示项目可以据实说不能仅凭这些画面说
I²S与PCM5102A实现的数字音频输出路径；现场确实可听时说明模拟链路有声。低于某毫秒的端到端延迟、低失真、无模拟底噪。尚无对应仪器测量。
双光电双束先后触发用于方向/速度相关处理；现场方向与声音结果分别记录。只遮一束、两束几乎同时触发或约150ms超时后备能证明方向/速度。50ms级状态轮询不是内部快速测量时基。
FFT / 李萨如内部数字PCM频谱与独立声部XY关系，单声部/高度相关时可能成线。模拟输出频响、真实左右声道、DAC噪声或示波器测量报告。
32路设计有32声部；请求数、门控、busy和逐路索引各有含义。稳定门控与声音是本次演示证据。只选“32”就证明所有路正常，或没有看overrun就宣布零溢出。FFT峰数不必等于声部数。
FSR有效ADC原码/表情量变化，并对应明亮度或拨弦阻尼变化。未经力学校准的公斤数、精确压力测量；过期值不能当实时数据。
手机状态本次有效回读与最终作业确认；保留提交/恢复的实弹证据。网页打开即FPGA已连接、下拉框即真实模式、保存文件即断电后自动生效。
新曲 / 和弦开发约定及最终配套验证后的实机表现；新曲为额外自定义曲。未烧录的V047已经板上通过，旧V046支持score/2，或新曲替换了三首预置曲。
模拟音频延迟“尚未使用示波器测量整机输入到模拟输出延迟。”用仿真周期、WAV、手机UI刷新速度、剪辑观感推算已实测低延迟。

以后补测延迟时，另行记录可重复的输入触发点、模拟输出观测点、统一时基及测量方法；在得到仪器记录前，不在片中放假波形或虚构数值。本参考不要求当前进行该测量。

6．调整到6分钟或8分钟

版本调整方式必须留下
6分钟以7:30版减90秒：开场减5秒、音色减5秒、三模式减15秒、Pads减5秒、FX减10秒、FSR减5秒、光电减5秒、FFT减5秒、32路减5秒、上传减5秒、映射减10秒、录音减10秒、结尾减5秒。每项至少一个可辨认的动作和结果；三模式差异、四Pad、FX、FSR、双光电、I²S、FFT/李萨如、32路、上传/映射/WAV及验证边界仍覆盖。等待过程可剪短并标“等待后”。
7分30秒使用第2节时间表。适合兼顾完整操作链和声音对比；若最终曲片段不够短，可调整其余段落。
8分钟在7:30版上加30秒：和弦逐音反例15秒，双键独立松键验证10秒，版本与证据说明5秒。和弦未验证时把15秒改成单音逐音正确/错误对照，不能为了凑时长宣称待开发功能已完成。

每个效果至少留一段听得出的声音。宁可缩短口头介绍和重复菜单，不要把完成状态、失败提示或必要恢复剪没。

7．开拍前与交片前核对

  • 记录实际使用的FPGA版本、ESP版本和烧录记录；两端新版未部署时明确标注。拔下ESP期间不安排手机实机镜头，不擅自连接或烧录。
  • 默认映射、KEY模式、合理音量、录音未占用、曲谱已暂停；备份映射和上一段WAV。新曲JSON先离线检查，确认版本兼容。
  • 硬件功能先短试：四Pad来源、软接管、两FSR数据有效、光电双束释放和方向、模拟输出可听；失败项保留待测。
  • 四键普通模式：短1切页、短2开始/暂停/继续、短3重播、短4选曲；长1音色、长2输入模式、长3测试、长4曲谱模式。长按约0.8秒后松手执行，测试视图按键含义另行切换。
  • 切离演奏页会暂停曲谱；拍FFT改用手动琴键。导奏实际状态过期时先刷新，录音期间不拿暂停刷新的页面当实时测量。
  • 映射镜头后已提交默认并实弹；32路镜头后已退出验证；WAV本次完成、drops与校验结果有证据，下载文件能打开。
  • 片中标明实拍、仿真预览、旧录音回放、待发布功能；不编造比赛时限，不填未测模拟延迟，不提供版权曲谱。
