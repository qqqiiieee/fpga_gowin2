# V034 → V047 更新说明

比较基线是仓库上一版提交 `d6295e39ca2d74b82c05a373665e5388a38f060b`，不是仅列 V046 到 V047 的变化。当前固件身份见根目录 manifest；中间版、对话、工具链缓存、Flash 个人数据备份不作为本次发布内容。

保留两种旋律音色、32 独立状态、双光电、双 FSR、四个 FX/音量旋钮。滑杆/MCP/矩阵及电容菜单仍停用；这部分主要变化已在上一版完成，不算本次新删功能。三效果仍互斥，并未增加三条并行效果链。

## 维护重点

1. FPGA/ESP 必须配套。能力字与 score/2 同步，旧 ESP V046 不识别新能力组合；HTTP 接收不等于 FPGA 提交成功。
2. 曲谱最多63组、每组1–4个升序唯一音高、MIDI41–72、四分之一拍网格、共享起始/时长、组间不重叠；不是任意多轨 MIDI。JSON velocity 当前不改变自动演奏固定力度192。
3. guide_chord_events 的来源3先 Off 再 On；guide_chord_modes 要求新触发且同时保持全部目标，踏板尾音不等于真实 held。
4. 映射只改变送合成器的音符；原始琴键高亮、练习判定与扫弦选音仍按物理 MIDI。修改须同时保护排队、NoteOff、延音和 Panic。
5. 录音不得恢复 seek(0) 改写大文件头；所有下载/USB读取走 readWavRange。录音15625Hz不是I2S的93750Hz。
6. N9 是复用脚，重建必须设置 use_sspi_as_gpio=1。禁用损坏脚清单与当前接线见接线文档。
7. 当前已有真实上传/下载、三模式状态与30秒非静音数字录音证据；模拟延迟、32路频谱、真实逐音和弦实弹、冷启动仍待确认。
8. 光电单束后备有150ms等待，不能对全部输入路径宣称≤10ms/≤5ms；应单独测试并改进。FFT/XY是只读监视，不应进入实时音频控制环。
