2．手机上传曲谱的完整步骤

  1. 先把所需 JSON 保存到手机“下载”或“文件”。热点不提供互联网，建议连接热点前完成文件传输。
  2. 两端上电并按既有接线通讯：ESP32 D17→FPGA L9、D16←N8、GND 共地。无需新增信号线；不要接回曾损坏的 PMOD 引脚。
  3. 手机连 Tang20K-Music，密码 fpga2026，浏览器打开 http://192.168.4.1/extensions，先确认链路已连接。
  4. 在自定义曲谱区点击文件选择，选中 JSON。文件导入只填入编辑框；再点“保存并上传 FPGA”，等待上传完成，不要仅凭文件名出现就判断成功。
  5. 选择“自定义”曲目，再选“自动演奏”并开始。HDMI 要停留在演奏引导页；离开此页会暂停引导。
  6. 等两拍预备后观察音符落下、对应键亮起与声音。切逐音练习或固定 BPM 前先暂停，切模式会重新开始当前曲谱。
旧版 V046 仅支持单音示例；“霓虹阶梯”需两端 V047。手机新固件会检查 FPGA 和弦能力，不会把旧固件的上传拒绝显示为成功。曲谱上传不会覆盖 FPGA Flash 固件。

三首内置曲仍是“小星星、灯阶练习曲、溪桥练习曲”。新曲使用第 4 个“自定义”槽，再传别的曲会替换该槽；不是无限追加曲库。FPGA 断电会丢失自定义 RAM，ESP32 保存的 JSON 可在重新上电后再次上传。

3．和弦在三种模式下怎么用

模式实际行为你要做什么
自动演奏FPGA 同时触发该组最多四个音；不是手机播放音频。真实 MIDI 仍可以手动发声。用于看谱听范奏，先空手观察新曲。
逐音练习每组等待全部目标键在进入该步后重新按下，并且同时保持按住；满足后继续走该组时值。一组三个音就三个都按住。逐个点一下再松开不能通过；重复和弦/共同音到下一组也要重新触发。暂停会清除未完成的尝试。
固定 BPM按谱面速度持续推进，不等待按对，不自动替你发声。跟随下落音符演奏，检验熟练程度；目前不提供自动准确率评分。

短按键仍为 1 切页、2 开始/暂停、3 重播、4 选曲；长按 4 循环三模式。特殊 32 路验证视图另有按键职责，以屏幕该页提示为准。

HDMI 会显示同组全部目标键及多条下落音符；手机原有“当前音符”回读字段显示该组根音，不能用它判断另三个音没有生效。练习基准采用原始物理 MIDI 键位，演示映射前后请恢复默认映射，避免声音与找键含义混淆。

pitches 必须升序、唯一，最多4音；同组共享起始和时值，不支持各声部独立长短的任意多轨 MIDI。不同组不得重叠；最多63组、曲谱本体61拍。保留 velocity 格式校验，但自动示范沿用原有固定力度192，不应宣称谱面 velocity 已控制示范音量。

5．回来后怎么确认鼓垫变响

  1. 两端升级完成后，先将总音量调低，FX 设为0，保持默认映射。
  2. 分别轻敲、重敲四个Pad，确认 Kick、Snare、Closed Hat、Open Hat 的力度变化仍在。
  3. 与旧版对比时用同一个总音量和类似击打力度；再同时弹琴敲鼓，旋律音量应保持原样，鼓声更突出。

离线 RTL 比较中，默认平衡下四鼓同时输出峰值由2597提升至5194；真实鼓声波形测试未出现新增饱和。这里只证明数字样本增益，实际耳机响度仍需听测。高总音量或强效果器仍可能使下游限幅，别把此结果理解为任何设置都不会失真。
