电源、分压与布线细节

  • 开发板保留原先已经验证可用的供电 / 下载接法。用 PMOD 的 3V3 和 GND 建两条配电母线，各低功耗外设并联分支；不要把电源接到普通信号脚。键盘与显示屏按各自规格使用 USB 5V 供电。
  • 新增两套 SEN0503 后，先逐个增接并测量 3.3V 带载电压。厂商标称工作电流 25mA，实际整机电流和 Dock 的可用余量未测，不能仅凭“同为 3.3V”认定供电够用。模块电源附近可按需加 100nF 去耦。
  • 若需要外置 3.3V 稳压供电：外设 VCC 改由该电源提供，地与 FPGA 共地，不能直接把两个独立稳压器的 3.3V 输出并联。先核对输出电压再连信号。
  • FSR 各自一只 10kΩ 下拉，GVS 用一只 10kΩ 串联和一只 10kΩ 下拉，双光电各一只 10kΩ 上拉：完整基础接法共用 6 只 10kΩ。已有同值电阻时不重复叠加。ADS 模块自带 I²C 上拉时无需再盲目并联。
  • GVS 外部分压理想值为 S/2，3.3V 满幅时约 1.65V。你的 MCP 板有 2.5V 参考及板载输入元件，端子到芯片的实际比例仍须测量和逐键标定；不能直接把商家模拟数表当成 12 位码。
  • 接线尽量短；ADC、FSR 和滑杆回地靠近 ADS 地，音频线远离 HDMI / SPI / 时钟长线。分组扎线并贴 A0、A1、OTA1、OTA2、beam A/B 标签，减少模拟量受数字回路干扰。
  • 矩阵按 R/C 丝印接线，不按排针数数推断。当前 R2=M14、R3=T12 是已修正映射。G/V/S 三线触摸板与八线矩阵接口不同，不能互换接法。

按这个顺序首次接通

  1. 所有器件断电后接线；先核对模块型号、丝印、3V3 / GND，以及 PMOD 背面与正面的镜像关系。
  2. 先保留板载耳机和 HDMI，按既有方式给 FPGA 供电。若要烧录，使用下方 V020 固件；本次没有生成新 fs 文件。
  3. 先接 ADS1115 和滑杆，检查 A2 改音量、A3 改基础音高。接两张 FSR 后重新启动，两张都松开约 1 秒；持续按住琴键，再分别按压力片观察明亮度 / VIB。
  4. 接 BMV 的 3.3V、GND、3脚 RX→T8，再将键盘 MIDI OUT 经 Type A 线接 BMV MIDI IN。键盘主旋律通道设 CH1，先测试单音和和弦。不要插到 BMV MIDI OUT。
  5. SP-2 插键盘 SUSTAIN；键盘断电连接，脚松开再上电。若踩下反而取消延音，断电后切换踏板极性再试。通过电脑 USB 测试工具可观察 CC64。
  6. 打击垫想用当前鼓声映射时，设置为 NOTE 模式、CH10；底鼓 Note35/36，军鼓 Note38/40。先读实际 MIDI 消息，再决定是否需要调整键盘设置。
  7. 接双光束：四端红线 3.3V、黑线 GND，A 白线 P8 / B 白线 P9，分别 10k 上拉到 3.3V。两束平行，沿手运动方向相距 3～5cm，先缩短光程对齐。
  8. 两束无遮挡后启动，保留至少 200ms 学习空闲电平。先分别遮 A / B 看诊断，再依次 A→B 和 B→A 扫过。3.3V 下厂商标称距离约 20cm，长时间遮住不会连续触发。
  9. 最后接 GVS / MCP3208 并逐键标定。单模拟编码输入按单键验收；多音和弦由 MIDI 键盘承担。原八线矩阵可保留菜单和组合键使用。
  10. 需要输入监视时，打开 V020 根目录“打开全部输入监视.cmd”。今天游戏期间我没有启动监视器、录音、烧录或后台编译。

测试尚未由本次操作完成，建议每接一组先验证，再接下一组。元件到货不等于链路测试通过。

ESP32 手机通信桥模块已拥有，但当前未集成生产用 ESP32 固件和通信接线方案，暂不接。后续可复用现有调试 UART T13 RX / M11 TX，但已与板上 USB 调试串口关联；不能让 ESP32 与 USB 调试器同时驱动同一输入，需先确定切换 / 隔离方案。当前不为它占用新脚。
屏幕 USB 触控、外接灯带按你的决定不启用。屏幕继续走 HDMI 显示；USB 只供电，实体键盘负责交互。
