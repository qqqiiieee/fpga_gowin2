V034｜面板切换音色，键盘与扫弦同时演奏

本版沿用V033全部物理引脚和F2–C5键位。四键只操作界面/参数，MIDI负责琴键和打击垫；三种输入模式共用现有32声部。

四键操作

按键 / PMOD3短按后松开长按约0.8秒后松开
1 / A11切换 HDMI 页面长笛 ↔ 拨弦音色
2 / B11开始 / 暂停 / 继续引导KEY → STRUM → HYBRID → KEY
3 / N6重播当前曲仍为重播，一次执行
4 / D11选下一曲并等待开始仍为选曲，一次执行

长按1/2不会再附带短按动作。所有操作在松手后执行；多键一起按会取消本次操作。上电时按住或诊断模式退出后，先把四键全松开再操作。按住操作键时教学谱面暂时冻结，音频不因此暂停。

三种输入模式

模式MIDI 琴键光电扫弦
KEY 键盘（上电默认）直接演奏所选音色不发声
STRUM 扫弦只选择按住的和弦，不直接发声依次弹出所选和弦，拨弦音色
HYBRID 混合直接演奏所选音色额外叠加当前和弦，拨弦音色

建议混合模式先选长笛，按住C/E/G听持续和弦，再依次遮挡A、B光束听拨弦叠加。反向遮挡改为反向扫弦。未按琴键时，光电沿用默认C4/E4/G4/C5。混合会让同音叠加更厚，先降低总音量；它共用32声部，不是额外增加32声部，满载仍沿用原有抢占规则。切模式会清掉旧声部和效果尾音；切完先松开并重新按琴键。

旋钮保持K1 Delay、K2 Chorus、K3 Reverb、K4总音量；效果器仍共用一条效果路径。两片FSR仍分别控制明亮度与拨弦阻尼。

手机不用接线，三根线固定在作品内部

ESP32 实物丝印FPGA PMOD3用途
D17 / GPIO17L9 / phone_uart_rxESP32 → FPGA
D16 / GPIO16N8 / phone_uart_txFPGA → ESP32
GNDGND公共信号地

三根UART线可以永久固定在作品内部，之后不用每次重新插拔。手机与ESP32通过Wi-Fi通信，无须手机数据线。ESP32 Type-C烧录完成后只需供电，可接合适USB电源或充电宝；FPGA也需要自己的正常供电。不把两块板的3V3输出相连，UART信号仍为3.3V逻辑。若想共用一个电源，用合适的USB供电分配给两块板供电口，不把5V接到PMOD的3V3脚。

  1. 给FPGA与ESP32上电，保留内部三根UART线。
  2. 手机连接Wi-Fi Tang20K-Music，密码 fpga2026。提示该网络无互联网时选择保持连接。
  3. 手机浏览器访问 http://192.168.4.1/，等待“FPGA已连接”变绿、参数同步完成。
  4. 选择音色或演奏模式；页面以FPGA实际回读为准，面板长按修改也会被手机后续读回。
  5. 不用手机时可断开Wi-Fi，板上面板、MIDI和扫弦继续运行。FPGA重新上电后恢复默认KEY模式，不自动恢复掉电前参数。
配套升级：V034的FPGA和ESP32固件要配套使用。旧ESP32仅允许模式0/1，遇到混合模式回读可能被判无效；升级两边后再测HYBRID。本页不是烧录成功记录，以根目录manifest.json和verification验证记录为准。
