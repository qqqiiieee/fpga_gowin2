V020：两个FSR改为连续演奏表情

接线保持原样：ADS1115 A0接第一张FSR，A1接第二张FSR，A2/A3仍接音量/音高滑杆。FSR不再触发鼓声；请先按住一个琴键，再用压力片改变正在演奏的声音。

控制器现在的作用操作与听感
FSR 1 / A0明亮度，连续滤波开合轻压/松开时柔和，重压时打开高频、音色更明亮。它改变频谱，不是另一个总音量旋钮；滤波会自然影响不同频率的幅度。
FSR 2 / A1揉弦深度 VIB不压时音高稳定；越压揉弦越深，约6Hz，满值约±1半音。基础音高继续由原滑杆或MIDI Bend决定。
滑杆 A2 / A3总音量 / 基础音高功能保留；与MIDI CC7/Bend仍按最近数值变化取得控制权。
MIDI CC1 / padsCC1揉弦 / CH10底鼓军鼓CC1和FSR揉弦取较大深度，不叠加；MIDI pads的鼓保留，FSR本身不会触发它们。

第一次怎么试

  1. 按本版本入口选择instrument_v020.fs。本版仍输出板载PT8211的3.5mm耳机；不需要MAX98357。
  2. 上电后先松开两张压力片约1秒，让每通道独立取得16个基线样本。不要在启动/重连标定期间压住，否则会把压力当作静止负载。
  3. 使用长笛音色，音量滑杆放中间偏上、音高滑杆回中。先按住一个琴键；拨弦会自然衰减，第一次对比不如长笛持续音直观。
  4. 保持琴键，单独缓慢压FSR 1：听柔和到明亮的变化；再单独压FSR 2：听稳定长音变为明显揉弦。最后两张一起压，组合两种表情。
  5. 松开FSR，揉弦平滑消失；再松开琴键。单独压FSR不应出现鼓声或新音符。
  6. 屏幕“明亮”和“VIB”显示实际平滑控制量0~255。若一直0，先看ADC故障/过期状态，确认A0/A1分压接线；若上电就较大，松开后重新启动标定。

这两个维度目前是全局表情，会影响所有共享旋律声部，不是每个琴键独立的Aftertouch/MPE。明亮度位于混音后，也会改变MIDI pads鼓的频谱；揉弦只改变旋律声部。FSR输出不是kg；“1kg”不能直接作为软件压力读数。

灵敏度与保护

ADC仍使用±4.096V档，1码=125µV。以静止基线为零点，增量≤64码（8mV）不生效；超过后按增量÷16映射并在255限幅，约4080码（0.51V）增量到顶。死区是门槛，未从增量中扣除；65码对应目标4。每个有效样本跟随目标距离的1/4，持续按压不会被向上的基线跟随吞掉。

每通道250ms没有新样本就独立清除表情并等待重新标定；另一个通道仍更新也不能掩盖断流。明亮度失效时回退原低通系数，键盘仍可发声。全局清音、数字零与32频验证不会被旧压力事件重新触发。

明亮度用y += alpha × (x-y)，alpha从8/256到135/256；93750Hz采样下数字截止频率约474Hz到11.75kHz。系数每16音频帧最多变1，配合压力平滑减少拉链声。原“滤波”开关不关闭已标定的明亮度表情。
