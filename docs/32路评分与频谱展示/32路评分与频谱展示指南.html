两条评分怎么证明，32路谱峰怎么展示

V047当前声明：32份独立声部状态；I²S设计采样率93,750Hz；32路全部活跃时设计吞吐量为3,000,000声部·采样/秒。本页不是一次新的实测报告。

官方赛题：选题二核心评分及现场验证

1．振荡器数量：结构和独立控制一起证明

依据V047当前实现展示方式
相位生产PHASE_RAM分支中的32×24bit相位RAM，每路有自己的累加状态。打开wavetable_synth.v的phase_ram段，不能只展示未启用的legacy phases寄存器分支。
频率与门控voice_allocator保存每路音高、力度、门控及触发状态。不同路使用不同频率，逐路关开时对应谱峰变化。
包络每路独立包络电平/阶段；实时ADSR有逐路状态与小数RAM，共用运算链。正常演奏按住多个音，分别松键，结合RTL及控制状态。

32个谱峰只证明有32个频率成分，不能单凭它排除单波形谐波；因此要与独立状态RTL和逐路关开结合。波表音色数、左右复制声道和谐波数量均不额外乘入振荡器数量。

2．吞吐量：先列设计值，再补测量

参数当前值
设计声部数32，实测时核对实际gate/busy与32个目标峰，不能只看requested。
I²S采样率27MHz÷288=93,750Hz；BCK=3MHz，每帧32bit。后续用示波器/逻辑分析仪实测LRCK作进一步佐证。
32路全活跃设计吞吐量32×93,750=3,000,000声部·采样/秒。
手机录音采样率15,625Hz（最终PCM每6点平均）；用于频谱捕获，不把这个速率拿去代替I²S采样率。

过采样、双声道复制、CPU时钟或FFT采样率都不另加分。可以先在报告中列出设计值，测量完成后再给“实测活跃声部数及采样率”。

3．现有硬件最快的32峰验证

  1. 先下载要保留的旧录音，因为开始新录音会替换上一段。连接ESP32和FPGA，确认手机控制链路正常，监听音量先调低。
  2. 松开琴键和踏板，暂停曲谱。薄膜按键3长按约0.8秒再松手，进入振荡器测试。
  3. 短按4请求全32路，等淡入结束。核对请求数32、门控32、忙碌32及overrun=0；逐路扫描应关闭。默认测试频率是400+97×i Hz（i=0..31），范围400..3407Hz。
  4. 手机打开http://192.168.4.1/extensions，录音秒数改5，点“开始实际PCM录音”。全程保持全32路测试。
  5. 等录音完成并校验通过，下载WAV。该文件记录真实板上最终数字PCM，不是仿真音频，也不是外部麦克风。
  6. 短按3退出振荡器测试，恢复普通演奏。保存录音文件、版本号、录音状态及板上32路状态的截图。

现有RTL的REC_START未禁止test_owned，记录点是最终PCM，因此这条捕获路线在实现上可用；当前没有连接到FPGA/ESP32 USB，本轮没有实际执行这次32路采集。

这一步能证明FPGA板内实际生成的频率成分，尚不包含I²S串行链路或DAC模拟输出的测量。要把DAC一起验证，可再用外接声卡Line In或带FFT的示波器采PCM5102A模拟输出。

4．怎样把WAV变成可展示的频谱

  1. 用Audacity打开下载的WAV，保持文件原生15,625Hz，不需要改成48kHz。
  2. 选取稳定的至少4.2秒，例如5秒录音中间一段。进入“分析→绘制频谱”（Analyze→Plot Spectrum）。
  3. 算法选Spectrum，窗选Hann，Size选65536，横轴选线性。15,625÷65,536≈0.2384Hz，比97Hz的目标间隔细得多。
  4. 对照下表找400、497、594……3407Hz的32个目标峰；不要把噪声或谐波凑数。导出频谱文本并保存截图。若图太挤，可把WAV交给项目助手生成300–3500Hz范围、32个编号的频谱图及误差表。

Audacity官方频谱说明：FFT、Hann、线性轴与数据导出。板载FFT为512点，抽取后Fs=11718.75Hz，频率bin约22.89Hz；可以辅助观察，但PC图更适合逐峰标号与核对。

5．独立性怎么拍得更有说服力

全32路稳定时短按测试面板2，启动逐路OFF/ON：先关闭第0路约0.5秒，再恢复0.5秒，然后第1路，以此到第31路。目标现象是对应频率峰降低/消失后恢复，其他峰保持。

完整扫描约32秒，而手机单段录音最长30秒。完整验收可以做两轮有重叠的分段采集，例如一轮录前段，另一轮重新扫描后从中段开始录后段；或使用能连续录40秒以上的外部声卡。不能把30秒文件说成已经覆盖全部32路。

测试声部的Release会使关闭后的峰逐渐降低，不一定在gate下降瞬间变成零。按稳定OFF/ON时间窗比较；扫检时requested一直是32，OFF阶段gate可为31，busy还包含尾音。

正式图注建议：“V047，板上实际最终PCM录音，15.625kHz，32个设计目标频率；该图验证数字合成输出，DAC模拟链另测。”
