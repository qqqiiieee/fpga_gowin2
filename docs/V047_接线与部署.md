# V047 接线与配套部署

以下以当前 [multi_tone.cst](../src/multi_tone.cst) 为准，不能照旧V034图接线。

| 功能 | FPGA针脚 | 外设 |
|---|---|---|
| MIDI输入 | PMOD0 T8 | BMV51M模块实物TX；键盘MIDI OUT接模块MIDI IN |
| 光电A/B | PMOD0 P8/P9 | 两路接收OUT；发射端与接收端均需正确供电对准 |
| ADS SCL/SDA | PMOD3 N9/N7 | ADS1115 SCL/SDA；VDD3.3V、GND共地、ADDR接GND |
| FSR | ADS A0/A1 | 两路原有3.3V分压节点；A2/A3停用接地 |
| 标准I2S BCK/LRCK/DIN | PMOD2 B12/C12/B13 | PCM5102A BCK/LRCK/DIN；SCK和FMT低、XSMT3.3V，电源按模块要求 |
| 面板1/2/3/4 | PMOD3 A11/B11/N6/D11 | 四个独立常开键，公共端GND，低有效，不接VCC |
| 手机RX/TX | PMOD3 L9/N8 | ESP D17/TX→L9，ESP D16/RX←N8；GND共地 |
| FTDI诊断 | T13/M11 | 板载JTAG&UART接口，115200bps |

手机UART为3.3V逻辑、1Mbps。两板各自供电，GND相连，两个3V3稳压输出不并联。PCM5102A是LINE OUT，低阻耳机直驱不能作为其正常线输出驱动能力的保证。

曾受损并禁用：PMOD0 T6/P6/R8/T7；PMOD1 T11/P11/T12/R11；PMOD2 D14/E15/B14/A15。其余未分配脚不应因旧图而被占用。切勿复用这些禁用脚验证新功能。

## FPGA

烧录根目录 instrument_handoff.fs（V047，UserCode0x00003608，SHA见manifest）。需要上电保留时，Gowin Programmer选外部SPI Flash擦除/编程/校验，而非只写SRAM；正常完成后重载并验证。已有记录通过Flash写入校验与重载，物理完全断电冷启动仍待记录。

修改后用Gowin1.9.12.04打开根工程，或在已授权Tcl Console执行 `source {完整路径/scripts/rebuild_gui_v047.tcl}`。该脚本保留use_sspi_as_gpio=1和当前PnR选项，仅编译。新文件在impl/pnr，不能用旧fs改名替代。

## ESP32

使用classic ESP32-WROOM32 / ESP32 Dev Module，core2.0.17。配套文件在firmware/esp32，烧录参数和地址见 [烧录映射](../firmware/esp32/烧录映射.json)：0x1000 bootloader、0x8000 partitions、0xe000 boot_app0、0x10000 app；dio、40m、4MB。不要整片擦除已有LittleFS曲谱、映射、录音。

源码编译：Windows先在esp32_phone运行 `python bootstrap_toolchain.py` 安装隔离工具链（需网络），再 `powershell -File build.ps1`。已有隔离工具链可用 `-ToolchainRoot` 显式指定。此构建不烧录；本次发布保留已验证的原应用二进制。

两端更新后手机连Tang20K-Music，密码fpga2026，打开 http://192.168.4.1/ ，待绿色且参数同步；扩展页 /extensions。曲谱选择JSON→保存并上传FPGA→确认激活。自定义槽只有一个，上传新曲覆盖旧曲；断电后从ESP重新激活。示例仅作为文件，不随固件预载。

普通短按1切页、2开始暂停、3重播、4选曲；长按约0.8秒后松开：1切音色、2切输入模式、3验证、4教学模式。验证页短按1循环1/4/8/16/32路，2逐路OFF/ON，3退出，4全32。
