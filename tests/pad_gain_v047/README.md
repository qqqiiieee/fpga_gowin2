## 位宽与真实上游

- 任意四路 PCM16 求和范围 -131072..131068，18 位有符号完整保存。
- 除 2 后 -65536..65534；乘最大平衡 255 后 -16711680..16711170，现有 26 位乘积足够。
- 与旋律在原 27 位加法寄存器相加，最后除 256 并饱和为 -32768..32767，不能先截成 16 位。
- `drum_voice.v` 三角幅值与包络给出绝对峰值 ≤8159；`snare_voice.v` 的噪声+主体 ≤8158；两种 `hat_voice.v` 各 ≤8159。
- 因而真实四鼓即便所有理论峰值同相，总和绝对值 ≤32635，除 2 后在 -16318..16317 内。
  和任意合法旋律 PCM 用互补平衡权重混合不会新增饱和；人为全量程四鼓仍由原饱和器保护。
- MIDI 原映射 `{v7,v7[6]}`、FX 和总音量链路从当前本地源码检查，未改动。
